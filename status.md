# Status — Real guest portraits

_Last updated: 2026-09-01_

`/guests` was cycling three placeholder avatars (`public/images/guests/{1,2,3}.png`).
It now shows **real guest faces**, cropped from each episode's YouTube thumbnail into
`public/images/guests/<videoId>.jpg` — 32 portraits, ~700 KB. The placeholders are deleted.

## Why this needed care

There is no headshot source anywhere in this tree — no guest photos in `Apps\podcast`, none
in the RSS feed (its `itunes:image` is show art). The thumbnails are the only place the
guests' faces exist. But the show has used **four different thumbnail templates**, and the
host is not always on the same side:

| Template | Era | Layout |
|---|---|---|
| A | 2024-05 → 2024-11 | raw video-call grid, 2–3 panes, Ved's pane varies |
| B | 2024-10 → 2025-12 | teal card, guest in a circle on the LEFT with a name label |
| C | 2025-06 → 2025-10 | studio cut-out, guest LEFT, Ved RIGHT |
| D | 2025-11 → 2026-04 | teal wedge, Ved LEFT, guest RIGHT, both names in a strip |

A single "crop the right side" rule would have put **Ved's face under a guest's name** on
roughly a third of the cards. So: all 47 thumbnails were downloaded, laid out as contact
sheets and classified by eye; crop boxes are keyed by publish date in
`scripts/crop-guest-portraits.ps1`; template A is excluded entirely rather than guessed at.
Every crop was then re-checked on a second contact sheet labelled with the guest name the
site would print beside it — which is how two bad name parses got caught
(`Purpose with Pacha's` → Maddie Hamann, `TerraSafe's Scott Bolin` → Scott Bolin).

Belt and braces at runtime: `portraitFor()` in `feed.ts` only attaches a portrait when the
guest's **surname appears in that video's title**. Title similarity is good enough to pick
a thumbnail; it is not good enough to put a name on a face.

## Parser fixes this surfaced

- The feed numbers episodes **two ways** — `Title | #42` early on and `#42 Title` later.
  Only the suffix form was handled, so the `#N ` prefix was being left in the title, which
  broke both numbering and YouTube matching. Numbered episodes **89 → 103**, episodes with
  a YouTube thumbnail **45 → 56**, portraits matched **18 → 29**.
- Guest names now take the **last** "with" in a title and drop a leading company
  possessive, so "Building a Brand with a Purpose with Pacha's Maddie Hamann" resolves to
  Maddie Hamann.

## Pipeline (kept in `scripts/`)

`fetch-thumbnails.ps1` → `contact-sheet.ps1` (classify) → `crop-guest-portraits.ps1` →
`contact-sheet.ps1` again (verify) → `build-guest-portraits.mjs`. All use .NET
System.Drawing via PowerShell — no image dependency added.
